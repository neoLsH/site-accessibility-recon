# 页面形态：先认形态，再谈分层

同一个 200 在静态页、CSR 空壳、降级软拦截里含义完全不同。形态决定**最小探测路径**，也决定
三态分诊的第一刀切在哪。认错形态的代价是拿错判据，后面所有单变量实验都在解释噪声。

## 八种形态

| 形态 | 识别信号 | 常见误判 | 下一步 |
|---|---|---|---|
| 静态直出 | 可见文本量正常，无空挂载点 | 把「有正文」当成「抓取没问题」，漏掉传输层拦截 | `matrix` 换栈对照，再与浏览器基线比完整率 |
| CSR 空壳 | 有 `#app` / `#root` 之类挂载点、脚本文本比高、正文接近 0 | 200 当成功；把整页字节数当完整率 | `surface` 看采集面，`matrix` 里加 headless 一栈 |
| 挑战页 | 非 2xx + 人机校验文案，或 200 + 极短响应体 | 当成硬阻断直接放弃，或当成内容不存在 | 按 [waf-classes.md](waf-classes.md) 归类，先修上层 |
| 登录墙 | 401、跳转到登录路径、密码输入框 | 当反爬反复换 IP；凭证过期却去改指纹 | 走 S7 合法凭证或 S0 换数据源 |
| 业务空态 | 404 / 410、200 + 明确的空列表/已删除文案 | 计入反爬分母，拉低可访问性成功率 | 内容业务状态，按业务处置 |
| API 响应 | `Content-Type` 为 JSON/XML，或正文以 `{` / `[` 开头 | 套 HTML 选择器，量出 0 字符 | 直接采 API，注意鉴权与限频 |
| 网关/错误页 | 5xx、默认错误页、连接重置 | 算作「被反爬」 | 基础设施噪声，单列，不进分母 |
| 降级 200 | 200 + 内容区显著小于基线 | 算成功；用整页长度掩盖缺块 | 只有基线能判：先取真实浏览器分布 |

“降级 200”无法从单个响应判出来——它需要**基线**。其他七种可以单响应初判。

## 分类器

```bash
scripts/recon.py shape https://example.com/page          # 1 请求
scripts/recon.py shape --html recon/raw/p1.html          # 离线复核
```

输出形态、关键信号（挑战文案 / 登录表单 / 挂载点 / 脚本数 / 可见文本长度）与下一步建议。
置信度固定为 **heuristic**：

- 它只描述「这份响应长什么样」，不判断「是否被反爬」。
- 挑战页与登录墙的文案判定会有假阳性（文章里提到验证、页头有登录框）。
- 形态结论必须用真实浏览器基线复核，再写进档案。

## 形态 → 实验路径

| 形态 | 第一发 | 第二发 | 不要做 |
|---|---|---|---|
| 静态直出 | `matrix` 同 UA 换栈 | 内容区与基线比 | 直接上 headless |
| CSR 空壳 | `surface` 静态扫 | `matrix` 加 headless 一栈 | 只加等待时间 |
| 挑战页 | `canary` 3–5 pass 看翻转 | 按 WAF 机制归类后选 S 级 | 直接解挑战 |
| 登录墙 | 核对凭证生命周期 | `quick` 确认是否稳定跳登录 | 反复换出口 |
| 业务空态 | 核对路由与状态码 | 换数据源（S0） | 计入反爬样本 |
| API 响应 | 直接请求 API | 看鉴权与限频 | 套浏览器栈 |
| 网关错误 | 复测 + 换出口对照 | 修链路/降并发 | 归因到指纹 |
| 降级 200 | 取浏览器基线 | `canary` 看内容长度是否翻转 | 把 200 当成功 |

## 与三态分诊的对应

- **反爬拦截态**：挑战页、硬阻断、降级 200、概率门。
- **内容业务状态态**：业务空态、登录墙（凭证问题本质是业务状态）、API 错误码。
- **链路失败态**：网关错误、连接重置、DNS/代理失败。

形态只是分诊的输入，不是结论。同一个「挑战页」仍可能是概率门，也可能是确定性闸门——
用 `canary` 的翻转率区分，别用单发猜。
